# Adventure Creator
*Check out my [**Medium post**](https://medium.com/@noltron000/decisions-adventures-and-trees-ca91a1885600) about choose-your-own-adventure stories!*

> ### Author's Note
> As an avid fan of *D&D*, *Undertale*, roleplaying games, and good stories in general, it's no surprise that I am passionate about some of their classic roots: *choose-your-own-adventure stories*.
> This medium for games and stories also really flourished alongside vintage command-line-based computers.
> There is something especially unique and exciting about this format, maybe its the combination of tech and the storytelling medium?
> So, what better way is there to celebrate it, than to create an app that helps you author them yourself.

This Python script can help you brainstorm branching "choose-your-own-adventure" stories.
Using this script, you can write your own stories and map out their branches.

![Branching Pathways](https://repository-images.githubusercontent.com/223473743/9fd5cc80-1613-11ea-8937-754e951c438a)

## Requirements
Python 3.14 or newer is required.

## Usage
1. Clone the project to a directory of your choice.
1. Navigate to the directory in your terminal.
1. Run `python source/main.py`.
1. Follow the on-screen prompts.
1. The app will generate a folder called `/story` in your current directory.
1. You will find `START.md` within. Read it to begin your journey!

## Example
Navigate to [`/example/START.md`](./example/START.md) to see an example story generated by this CLI.

## Testing
The test suite requires pytest 7 or newer. Install it with `python -m pip install "pytest>=7"`, then run `python -m pytest`.
